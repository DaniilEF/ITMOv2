# Спецификация фичи: Фильтр существующего списка
Цель: фильтрация по подстроке, регистронезависимо; пустой результат; валидация недопустимого ввода; сброс.

Сценарии (Given/When/Then):
- happy_path: при вводе допустимой подстроки видны соответствующие элементы.
- validation_error: при вводе недопустимого запроса показывается ошибка.
- boundary_empty: при допустимой подстроке без совпадений показывается пустое состояние.
- reset_returns_full: при сбросе показывается полный список.

- specs/skit/logic.spec.yaml
- specs/skit/contract.spec.yaml
